# EduLearn Frontend

React.js frontend for EduLearn LMS — connects to 7 backend microservices.

## Setup
npm install
npm start

## Backend Services Required
- AuthService: http://localhost:5001
- CourseService: http://localhost:5002
- LessonService: http://localhost:5003
- EnrollmentService: http://localhost:5004
- AssessmentService: http://localhost:5005
- ProgressService: http://localhost:5006
- ReviewService: http://localhost:5007
